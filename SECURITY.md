# Security policy

Report vulnerabilities privately through GitHub's "Report a vulnerability" button on this repository. Do not open a public issue.

You get an answer within 7 days. Whistledoor is run by one person, so there is no 24/7 response.

In scope: `packages/crypto`, `apps/report`, and the published design docs. Findings that let anyone other than the tenant's case handlers read a report's content matter most.
